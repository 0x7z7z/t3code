Setup checklist
  1. Restart Premiere after installing. Open Window > Extensions > Axis.
  2. Click Try again to restart the local backend. Axis includes Node and Git.
  3. If a file is missing, review Windows Security > Protection history and reinstall from your trusted Axis installer. Your conversations are kept.
  4. Axis listens only on this laptop. You do not need to allow public network access in a firewall prompt.
  5. When the workspace opens, choose Accounts to install and sign in to a provider.
